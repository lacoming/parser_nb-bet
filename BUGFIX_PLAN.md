## Баги (критичные)

### BUG-1: Неправильный расчёт ratio для ставки 1X
- **Проблема:** ratio считается по коэффициенту 1X (kf_1x), а должен считаться по **kf_1**.
- **Пример из лога:** `1X kf=1.52 ratio=0.552/1.10 | FAIL` — используется kf 1X=1.52 вместо kf 1.
- **Формула:** `KfKush_1 * (1 + ROI) / KfNB_1 > threshold` — для ставки типа 1X ratio считать по kf_1, не по kf_1x.
- **Файлы:** `src/kush/bet_placer.py`, `src/decision/engine.py`
- **Проверка:** лог должен показывать ratio по kf_1 для ставок типа 1X.

### BUG-2: Несовпадение времени матчей (часовой пояс Куша)
- **Проблема:** матч на Куше 1:30 26-го, а NB показывает 22:30 25-го. Матч не находится из-за расхождения времени.
- **Задача:** выяснить точный часовой пояс, в котором Кush отдаёт время (MSK? UTC? другой?). Привести оба источника к единому UTC.
- **Файлы:** `src/kush/client.py`, `src/kush/matcher.py`, `src/nb/client.py`
- **Проверка:** матчи с разницей в пределах ±3ч должны матчиться корректно.

### BUG-3: Добавить поиск по латинским slug-названиям (дополнительный матчинг)
- **Проблема:** русские переводы команд на Куше могут сильно отличаться от NB. Предыдущий разработчик использовал латинские slug из URL Куша (совпадение ~98%).
- **Задача:** добавить параллельный поиск по латинским slug-названиям как дополнительный способ матчинга. Не убирать текущий fuzzy-поиск по русским — оба работают одновременно, берётся лучший результат.
- **Файлы:** `src/kush/client.py`, `src/kush/matcher.py`, `src/kush/normalizer.py`
- **Проверка:** матчинг должен находить матчи и по русским, и по латинским названиям.
