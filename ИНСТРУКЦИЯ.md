  # Настройка config.json

  Скопируйте `config.example.json` → `config.json` и заполните:

  ```json
  {
    "kush": {
      "login": "ваш_логин",
      "password": "ваш_пароль",
      "dry_run": false,
      "default_stake": 100
    },
    "nb": {
      "login": "email@example.com",
      "password": "ваш_пароль",
      "dry_run": false,
      "default_stake": 1000
    },
    "telegram": {
      "token": "123456:ABC-DEF...",
      "chat_ids": [123456789]
    }
  }
  ```

  ## Что значит dry_run

  - `true` — тестовый режим, ставки не размещаются
  - `false` — реальные ставки

  ## Пороги ставок (thresholds)

  ```json
  "thresholds": {
      "roi": 0.05,
      "default_ratio": 1.10,
      "big_league_ratio": 1.05,
      "big_leagues": ["Премьер-лига", "Ла Лига"]
  }
  ```

  Ставка проходит если `КфКуш × (1 + ROI) / КфНБ > ratio`.

  ## Расписание (schedule)

  ```json
  "schedule": {
      "start_time_msk": "08:00",
      "interval_hours": 4,
      "window_days": 14
  }
  ```

  ## Файлы рядом с exe

  ```
  parser_nb-bet.exe
  config.json        ← обязательно
  leagues.xlsx       ← обязательно
```
